# Security Policy

## Data Storage & Privacy

- **Local Storage:** All application data (chat metadata, folders, settings, custom providers) is stored locally on your device in an SQLite database (`centrallm.db`). CentraLLM does not collect, process, or transmit your prompts or chat content.
- **Third-Party Providers:** Interactions with web-based LLMs occur directly with each provider. Any data submitted on these sites is governed by the respective provider's privacy policy and terms.

---

## Reporting Vulnerabilities

If you discover a security vulnerability, please report it responsibly:

1. **Do not** open a public issue.
2. Submit details privately via the repository's security disclosure feature.
3. Include clear steps to reproduce the issue.
